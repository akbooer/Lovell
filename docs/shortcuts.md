
There are keyboard shortcuts for a number of different actions.  Some of them work from any page, others are specific to a particular one.

## Global Shortcuts

The user interface components are somwhat different from the standard ones used, so to augment their functionality there are some mouse/key based shortcuts:

  * right-click on any text input field clears any current text
  * right-click (or shift-click) resets slider or menu controls to their default
  
For spreadsheet tables:

  * left-click selected an item
  * shift click selectes a contiguous set of items between cursor and previous selection
  * command-click adds or removes single selecterd item from the current selection
  * double-click generally performs some table-specific action
  

!!! tip
    ESC key returns to the main display from any page

Command- or Ctrl- depending on operating system:

| ⌘-Key | Action |
| :----: | -------- | 
| C | Calibration masters database | 
| D | DSO database |
| E | Eyepiece mode |
| F | FITS headers |
| L | Landscape mode |
| O | Observations database |
| P | Plugin workflow editor |
| S | Settings page |
| V | View stack of subs |


## Page-dependent Shortcuts

| ⌘-Key | Action |
| :----: | -------- | 
| T | Toggle between Eyepiece and Landscape mode |
| 7 | Scale to fill screen, possibly cropping one axis |
| 8 | Scale to fill screen, possibly leaving a margin |
| 9 | Fit to margins between control and information panels|
| 0 | Full size - one image pixel is one screen pixel |
| + | Zoom in |
| – | Zoom out |
| . | Rotate_to_zero |
| / | Rotate_clockwise, +90º |
| \ | Rotate_anticlockwise, -90º|


There are keyboard shortcuts for a number of different actions.  Some of them work from any page, others are specific to a particular one.

## Global Shortcuts

ESC key returns to the main display from any page

Command- or Ctrl- depending on operating system:

| ⌘-Key | Action |
| :----: | -------- | 
| C | Calibration masters database | 
| D | DSO database |
| E | Eyepiece mode |
| F | FITS headers |
| L | Landscape mode |
| O | Observations database |
| P | Plugin workflow editor |
| S | Settings page |
| V | View stack of subs |


## Page-dependent Shortcuts

### Main Page

| ⌘-Key | Action |
| :----: | -------- | 
| T | Toggle between Eyepiece and Landscape mode |
| 7 | Scale to fill screen, possibly cropping one axis |
| 8 | Scale to fill screen, possibly leaving a margin |
| 9 | Fit to margins between control and information panels|
| 0 | Full size - one image pixel is one screen pixel |
| + | Zoom in |
| – | Zoom out |
| . | Rotate_to_zero |
| / | Rotate_clockwise, +90º |
| \ | Rotate_anticlockwise, -90º|
